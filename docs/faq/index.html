FAQ

よくあるご質問

ご相談前によくいただくご質問をまとめました。
掲載のない内容は、お問い合わせフォームからお気軽にお尋ねください。

初回相談には料金がかかりますか？

初回相談は、まず現状のお悩みをお聞きする場としてご用意しています。具体的な料金・実施方法は、お問い合わせ時にご案内します。※詳細条件は確認の上、確定します。

現在の税理士がいても相談できますか？

はい。顧問変更が前提でなくても、現状の課題整理だけでもご相談いただけます。今の顧問関係を維持したまま、財務・経営判断のセカンドオピニオンとして関与することも可能です。

顧問税理士を変更する必要がありますか？

必ずしも変更は必要ありません。ご希望に応じて、切り替えに必要な手続き（税務署への届出・資料の引き継ぎ）はこちらでサポートします。まずはご状況をお聞かせください。

オンライン相談は可能ですか？

はい、可能です。面談は原則WEBで対応しており、全国どこからでもご相談いただけます。

対応地域はどこですか？

オンライン対応を基本とし、全国からのご相談を承ります。※対面対応の可否・範囲は確認の上、ご案内します。

会計ソフトの導入や運用も相談できますか？

はい。クラウド会計の導入・運用設計に対応しています。対応可否はご利用中のソフトや運用状況により異なりますので、まずは現状をお聞かせください。※対応範囲は確認の上、ご案内します。

法人と個人事業主の、どちらに対応していますか？

どちらにも対応しています。法人・個人事業主・創業期それぞれに適したサービスをご用意していますので、サービス一覧から該当する入口をお選びください。

経営や資金繰りの相談も可能ですか？

はい。税務・会計の枠にとどまらず、納税予測・資金繰り・経営判断まで含めて支援します。より深い経営・財務の支援（外部CFO・資金調達・事業承継等）が必要な場合は、関連会社 株式会社C-suite & Co. が提供します。

料金の目安を教えてください。

税務顧問 C-suite Tax Advisory は、Entry 月額30,000円〜／C-Tax Start Pack 50,000円〜（創業3年以内限定）／Standard 80,000円〜／Premium 120,000円〜（いずれも税抜・最低料金）。決算・法人税申告料は200,000円〜（税抜）です。詳細は法人のお客様ページをご覧ください。

プランの違いは何ですか？

全プランに月次会計・税務相談・月次経営レポート・将来アラート・毎月の動画解説・申告が含まれます。違いは「経営参謀」の有無と頻度です。Entryは必要時オプション、C-Tax Start PackとStandardは隔月、Premiumは毎月の経営参謀MTGが付き、Premiumでは税務・会計管理の密度も高まります。

C-Tax Start Pack は誰が対象ですか？

開業・設立から3年以内、かつ年商1億円以下の方が対象の創業期限定プランです。どちらかを超えた場合は、通常プラン（基本はStandard、経営支援が不要な場合はEntry）への移行をご案内します。
